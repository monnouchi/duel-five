# Duel Five

**[ブラウザで遊ぶ](https://monnouchi.github.io/duel-five/)** — インストール不要。

1〜5の5枚で勝負する、一人用CPU対戦カードゲームです。5ラウンドの得点で勝敗を決め、5人の相手に順番に挑みます。

## はじめ方と操作

最初のルール説明で「遊ぶ」を押して開始します。

- **スマホ:** 手札をタップして選択。同じ札をもう一度タップするか、「この札で勝負」で確定します。別の札をタップすれば選び直せます。
- **PC:** 同じ操作をクリックで行います。Tabでボタンへ移動し、Enter / Spaceでも操作できます。
- 公開演出の間は操作を待ってください。素早い連打では札を確定しません。
- 第1〜3ラウンドの結果が出たら、残り札を直接選んで次へ進めます。第4ラウンドの後は「残り1枚で最終決着を見る」を押すと最後の札が自動公開されます。

## ルールと勝敗

1. 自分とCPUがそれぞれ1〜5の札を1枚ずつ持ち、選んだ札を同時に公開します。CPUはプレイヤーが札を選ぶ前に、出す札を決めています。
2. 大きい数字が勝ちます。ただし **1は5に勝ちます**。同じ数字ならそのラウンドは引き分けです。
3. 使った札は戻りません。CPUの残り札と公開履歴を見て、次の札を選びましょう。
4. 第1〜3ラウンドの勝者は1点、第4〜5ラウンドの勝者は2点。引き分けなら双方0点です。
5. 必ず5ラウンドを行い、合計得点の多い側が勝ちます。同点なら試合も引き分け。勝ったラウンド数だけでは決まりません。

## 5人勝ち抜きとメダル

先鋒ソラ → 次鋒リン → 中堅ガイ → 副将レイ → 大将アルクの順に対戦します。勝てば次へ、引き分けなら同じ相手と再戦。負けるとその周回が終了し、次は先鋒から再挑戦します。相手の傾向はルール画面で確認できます。

| 到達結果 | メダル |
| --- | --- |
| 5人全員に勝つ | 金 |
| 4人に勝ち、大将に敗れる | 銀 |
| 3人に勝ち、副将に敗れる | 銅 |

それより前の敗北と引き分けではメダルは増えません。結果を再読み込みしても成績やメダルは重複しません。

## 配色・音・保存・共有

右上の **Auto / Light / Dark** で配色を選びます。Autoは端末の設定に合わせます。音は初期OFFで、音ボタンで切り替えられます。端末の動きを減らす設定では演出を簡略化します。

進行・通算成績・メダル・設定は同じブラウザに保存されます。端末間の同期はありません。途中で閉じた試合は成績に数えず、再開時は同じ相手との第1ラウンドから始まります。完了した試合の結果は再読み込み後も確認できます。ブラウザの保存データを消すと記録も失われます。

試合結果・周回の終幕にある「共有」から、結果画像の保存や文章のコピーができます。対応端末では画像と文章を共有先へ渡せます。画像は端末内で作り、共有先の選択と投稿は自分で行います。
