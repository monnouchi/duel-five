# Duel Five

**[ブラウザで遊ぶ](https://monnouchi.github.io/duel-five/)** — インストール不要。

1〜5の5枚で勝負する、一人用CPU対戦カードゲームです。5ラウンドの得点で勝敗を決め、5人の相手に順番に挑みます。

## 操作とルール

ルール説明の「遊ぶ」で開始します。手札をタップ／クリックして選び、同じ札をもう一度押すか「この札で勝負」で確定します。PCではTabで移動し、Enter / Spaceでも操作できます。公開演出の間は操作を待ってください。

- 大きい数字が勝ちます。ただし **1は5に勝ちます**。同じ数字は引き分けです。
- 使った札は戻りません。CPUはプレイヤーが選ぶ前に出す札を決めています。
- 第1〜3ラウンドは勝者に1点、第4〜5ラウンドは2点。5ラウンドの合計得点で勝敗を決め、同点は引き分けです。
- 第4ラウンドの後は「残り1枚で最終決着を見る」で最後の札を公開します。
- 勝つと次の相手へ進み、引き分けは同じ相手と再戦、敗北は先鋒から再挑戦します。5人全員に勝つと金、4人に勝って敗れると銀、3人に勝って敗れると銅メダルを獲得します。

## 配色・音・保存・共有

右上のAuto / Light / Darkで配色を選びます。音は初期OFFで、音ボタンで切り替えられます。

進行・通算成績・メダル・設定は同じブラウザに保存されます。端末間の同期はありません。途中で閉じた試合は成績に数えず、再開時は同じ相手との第1ラウンドから始まります。完了した試合の結果は再読み込み後も確認できます。ブラウザの保存データを消すと記録も失われます。

結果画面の「共有」から画像の保存・文章のコピーができます。対応端末では画像と文章を共有先へ渡せます。投稿は共有先で自分で行います。

## 配布とソースからの利用

ブラウザ版は上の「ブラウザで遊ぶ」から利用できます。ソースはこのリポジトリのファイル一式です。Node.js 20以上で、追加パッケージのインストールは不要です。

```sh
npm test
npm run build
npm run preview
```

表示されたローカルURLで確認できます。`dist/` は静的サイトの配布用で、`index.html`、`src/`、`assets/`、`README.md`、`LICENSE`を含みます。改変・再配布時はMITの著作権表示と許諾全文を保持し、第三者素材の告知も添えてください。テストと画像生成用HTMLはソース側に保持しています。
